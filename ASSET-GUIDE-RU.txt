PONY CARDS HTML5 — ПАМЯТКА ПО ЗАМЕНЕ ГРАФИКИ

Все пути ниже указаны относительно папки html5/. Не меняй имена файлов.
После добавления или замены изображений обнови страницу Ctrl+F5.

1. КАРТЫ-АРТЕФАКТЫ (30 штук)
Папка: assets/user-content/cards/
Формат: PNG, рекомендуется 1024×1536 (2:3).
Экспортируй готовую карточку целиком: арт артефакта + рамка редкости.
Не добавляй текст/название/описание внутрь изображения.
Имена всех 30 файлов перечислены в assets/user-content/cards/README.txt.
Просто замени PNG с тем же именем — ID карточек менять не надо.

2. ПЕРСОНАЖИ
Три текущих персонажа находятся в assets/characters/.
Для дополнительных слотов 4, 5 и 6 используй assets/user-content/characters/.
Для каждого слота нужны три PNG: character-N-menu.png, character-N-flight-open.png,
character-N-flight-folded.png, где N — 4, 5 или 6. Полные примеры — в README этой папки.
Слот автоматически станет доступен, когда все три файла будут на месте.

3. КОЛОННЫ
Текущий фиолетовый набор находится в assets/obstacles/purple/ и уже активен.
Для дополнительных слотов 2–6 используй assets/user-content/columns/.
Имена: column-N-shaft.png (труба 512×1024) и column-N-base.png (основание 512×320).
Нужны оба файла одного номера. Слот автоматически активируется после добавления пары.
Сохраняй одинаковые пропорции, прозрачность и геометрию стыка с текущими текстурами.

4. ГДЕ ВЫБИРАТЬ
В игре открой «Скины» → «Персонажи» или «Колонны».
Выбор персонажа и колонн сохраняется локально в браузере.

5. ВАЖНО
Не удаляй старые файлы и не переименовывай ID карт. Не нужно редактировать JS или
asset-manifest.json для перечисленных слотов: поиск файлов выполняется автоматически.

Новые карточки v1.3.0: alicorn-amulet.png, storm-staff.png, starswirl-diary.png, magic-tide.png.
