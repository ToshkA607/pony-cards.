# HTML5 Local v1.1.0

## Обновление колонн
- Программная отрисовка обычных лётных колонн заменена двумя PNG-ассетами: прямой фиолетовой трубой и отдельным декоративным основанием.
- Верхняя колонна использует основание в обычной ориентации; основание нижней колонны переворачивается вертикально.
- Геометрия препятствий, генерация, движение, расстояние между колоннами и проверки столкновений оставлены без изменений.
- Добавлен программный fallback на прежнюю простую отрисовку на случай, если PNG не загрузились.
- Добавлены исходные PNG в `assets/obstacles/purple/` для будущих скинов колонн.
