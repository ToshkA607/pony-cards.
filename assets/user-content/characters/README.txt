В игре уже есть 3 персонажа: Искорка, Радуга и Флаттершай.
В галерее зарезервированы ещё 3 слота. Чтобы открыть слот, добавь ВСЕ три файла
для одного номера. Формат PNG с прозрачным фоном.

СЛОТ 4:
  character-4-menu.png          — портрет/изображение на главном экране и в галерее
  character-4-flight-open.png   — полёт с раскрытыми крыльями
  character-4-flight-folded.png — полёт со сложенными крыльями

СЛОТ 5: те же имена с номером 5.
СЛОТ 6: те же имена с номером 6.

Пути: html5/assets/user-content/characters/
Рекомендуется прозрачный PNG. Для полётных спрайтов сохраняй одинаковые пропорции,
примерный масштаб и положение персонажа, чтобы анимация не дёргалась.
Слот станет доступен автоматически, когда все 3 файла будут найдены.
После добавления обнови страницу Ctrl+F5.
