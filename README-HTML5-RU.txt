PONY CARDS — SKY ADVENTURE / HTML5 LOCAL BUILD
Версия подготовки: 1.0.0

Эта папка — отдельная HTML5-копия проекта. Она не использует Java, Spring Boot,
H2 или сервер Render. Вся игровая логика по-прежнему выполняется в браузере.

ЗАПУСК В VSCODIUM
1. Распакуй папку Pony-Cards-HTML5.
2. Открой именно эту папку в VSCodium.
3. Установи расширение Live Server, если оно ещё не установлено.
4. Открой index.html и нажми Go Live (или ПКМ -> Open with Live Server).
5. Игра откроется в браузере на локальном адресе вида http://127.0.0.1:5500.

СОХРАНЕНИЯ
Прогресс хранится в localStorage браузера под ключом ponyCardsHtml5Save_v1.
Сохранения остаются на этом браузере и устройстве. Очистка данных сайта может
удалить прогресс. Пока не подключены облачные сохранения Яндекс Игр.

ВАЖНО
- Исходная Java-версия не изменялась.
- Первый запуск HTML5 создаёт новый локальный профиль (30 стартовых монет).
- Старый профиль Render/H2 автоматически не переносится.
- Для проверки можно пользоваться магазином, карточками, улучшениями,
  ежедневными наградами/заданиями, достижениями, кампанией и полётами.
- Эта сборка предназначена для локальной проверки. Интеграция Яндекс Игр
  намеренно отложена до завершения разработки.

Если при запуске появится ошибка, пришли скриншот консоли браузера (F12 -> Console)
и напиши, какой шаг выполнял.

ОБНОВЛЕНИЕ КОЛОНН (v1.1.0)
