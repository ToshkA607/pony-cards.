# HTML5 Local v1.0.0

- Создана самостоятельная HTML5-сборка игры в отдельной папке.
- Удалена runtime-зависимость от Java / Spring Boot / H2.
- Перенесены серверные операции в локальный JavaScript-слой:
  профиль, магазин, открытие наборов, pity-счётчики, коллекция,
  избранное, экипировка карт, улучшения, кампания, рекорды,
  ежедневная награда, задания и достижения.
- Прогресс сохраняется в localStorage браузера.
- Добавлена инструкция запуска через Live Server в VSCodium.
- SDK Яндекс Игр намеренно не подключался.
- Оригинальные игровые механики, графика, музыка и интерфейс сохранены.
