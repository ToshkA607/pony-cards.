ПАПКА ДЛЯ ИЗОБРАЖЕНИЙ ПЯТИ ДОПОЛНИТЕЛЬНЫХ СКИНОВ

Твайлайт Спаркл уже подключена и хранится отдельно в assets/characters.
Пять свободных слотов автоматически активируются, когда вы добавите изображения с точными именами:
  slot-2.png
  slot-3.png
  slot-4.png
  slot-5.png
  slot-6.png

Формат: PNG. Рекомендуется прозрачный фон, персонаж по центру; лучше квадратное или вертикальное изображение.
После добавления файла обновите страницу браузера (Ctrl+F5). Код менять не потребуется.
