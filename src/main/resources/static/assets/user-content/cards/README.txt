PONY CARDS — КОЛЛЕКЦИЯ ИЗ 30 АРТЕФАКТОВ

В коллекции ровно 30 карточек. Для каждой карточки используется постоянный ID,
а имя PNG совпадает с ID. Не переименовывай ID в базе данных и в asset-manifest.json.

Папка для изображений:
src/main/resources/static/assets/user-content/cards/

Добавляй изображения в PNG 1024×1536 (портрет 2:3). Подойдёт и другое разрешение
с теми же пропорциями. Изображение целиком помещается в рамку: обрезки по высоте
или ширине быть не должно.

КАК ДОБАВИТЬ КАРТИНКУ:
1. Скопируй PNG в эту папку.
2. Назови файл строго как указано выше, например golden-blessing.png.
3. Перезапусти приложение или обнови страницу с очисткой кэша (Ctrl+F5).
4. Карточка останется скрытой в коллекции, пока игрок не получит её из набора.
   После получения появится соответствующая иллюстрация.

Не нужно редактировать JavaScript или asset-manifest.json: пути для всех 30 карточек
уже прописаны автоматически.
